# ✦ MBTI 人格测试

> 一个纯前端、零依赖的 MBTI 人格测试静态网站：**24 道题 · 约 5 分钟 · 发现你的人格密码**。

## ✨ 特色

- **面向年轻人的体验**：打字机开场、实时四维雷达图、选项滑片指示器、页面转场、光标辉光、噪点纹理等高级感微交互
- **准确性优先的计分**：4 点迫选量表（无中立）+ 逐题方向标注 + 双侧均值差分计分，识别乱答/中庸作答，模糊维度诚实标注
- **丰富的解读报告**：16 型 × 特质总览双向条 / 优势劣势 / 内在驱动力 / 职业规划 / 人生指导 / 冷知识，按 16personalities 风格组织，每种类型有专属主题色
- **分享传播**：一键生成可下载的人格卡片 PNG、复制分享文案、最佳搭档推荐
- **彩蛋**：四维全模糊时显示「你是个复杂的人，MBTI 框不住你」
- **移动优先响应式**：480 / 768 / 1024 三档断点

## 🛠 技术栈

HTML5 + CSS3 + 原生 JavaScript（零框架、零构建、零 npm 依赖）

## 📁 文件结构

```
├── index.html      首页（打字机标题 + 开始按钮 + 人数统计）
├── test.html       答题页（进度条 + 实时雷达图 + 四选一 + 实时画像预览）
├── result.html     结果页（徽章 + 特质总览 + 完整人格报告）
├── style.css       全部样式（三页共享）
├── script.js       全部逻辑（题库、计分、16 型数据、渲染、分享）
├── mbti-logic.test.js  计分逻辑自动化测试
└── 开发文档.md         完整开发文档（设计理念 / 准确性保障 / 技术方案）
```

## 🚀 本地运行

双击 `index.html` 即可，无需安装任何东西。

## ✅ 自动化测试（可选，需 Node）

```bash
node mbti-logic.test.js
```

预期输出 25 项断言，全部通过说明计分正确。
